Build a **Next.js 15 + TypeScript** frontend-only web application that is fully compatible with **Vercel deployment**. Do **not** use any backend, database, APIs, authentication services, or external storage. Everything should work from local JSON files and static assets.

## Project Purpose

This website is a **private music preview portal** for sharing music with film directors and producers.

Instead of sending MP3 files through WhatsApp, I want to host them on a password-protected website.

This is **not meant to be secure authentication**. It is only a simple frontend gate to organize projects and avoid casual sharing.

### One important note

Because this is a **frontend-only app**, the username/password in `projects.json` and the MP3 files inside `public/` will still be accessible to someone who deliberately inspects the deployed site or its files. This approach is good for **organizing previews and discouraging casual sharing**, but it is **not secure protection**.

If, in the future, you want only invited directors/producers to access music privately, the smallest upgrade would be to keep the same UI and add a tiny serverless backend (using Vercel Functions or Edge Middleware) to verify passwords and stream audio. The rest of the app could remain almost identical.
